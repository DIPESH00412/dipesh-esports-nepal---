DIPESH ESPORTS — ANDROID APK BUILD KIT

Yo project GitHub Actions ko free build runner bata debug APK banauna tayar cha. Chat bata direct APK compile bhayeko hoina; GitHub ma upload garera workflow chalaye pachi APK download garna milcha.

PHONE BATA BUILD GARNE TARIKA:
1. ZIP extract garnu.
2. github.com ma sign in garnu, naya PUBLIC repository `dipesh-esports-android` banaunu.
3. Extract gareko folder bhitra ko sabai FILES ra FOLDERS (app, .github, build.gradle, settings.gradle, gradle.properties) repository ko root ma upload garnu. `.github/workflows/build-apk.yml` path jastako tastai hunuparcha.
4. Upload/commit garepachi repository ko Actions tab kholnu.
5. `Build Dipesh Esports APK` workflow select garnu. `Run workflow` dekhiyo bhane tap garnu; push bhayepachi automatic run pani huncha.
6. Green check aayepachi build run kholnu, Artifacts ma `Dipesh-Esports-debug-APK` download garnu.
7. ZIP extract garera `app-debug.apk` tap garnu. Android le prompt garyo bhane browser/file manager lai Install unknown apps permission dinu, APK install garnu.

IMPORTANT:
- Yo DEBUG APK ho, Google Play release build hoina.
- GitHub repository public hune bhayekale code public dekhina sakcha; kunai password, secret, player data nahalnu.
- Current app demo matra ho. Registration/profile/event data shared online hudaina; real payment processing chaina.
- App source app/src/main/assets/www/index.html ma cha.
- Package ID: com.dipeshe.esports
